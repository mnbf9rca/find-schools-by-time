# Licensing and terms for publishing find-schools-by-time publicly

Researched 13 September 2026. The headline: the two government datasets are free to republish with attribution, postcodes.io is usable but undocumented on limits, and TravelTime is the blocker — the free Basic plan forbids exactly what you want to do.

## 1. TravelTime

1. **The free Basic plan does not allow a public site, commercial or not.** The Terms of Service say Trial and Non-Paid Services are "for internal use and evaluation only and are not to be made available to Customer's End Users", and separately that "No commercial use or profit-making purposes are permitted". The public-site problem is the first clause, not the second: visitors to a free hobby site are End Users. The pricing page agrees, describing Basic as "Free forever for research, development and evaluation — not for commercial use", limited to 120 hits per minute. <https://traveltime.com/terms-of-service>, <https://traveltime.com/pricing>
2. **"Non-commercial" is not a self-serve tier.** The Terms mention non-commercial customers only in the caching clause, which lets a customer "using the Service for non-commercial use (e.g. university/school)" keep copies if refreshed every 30 days. That clause describes a term negotiated in an Order, not the free plan. If you want a non-commercial arrangement you have to ask their sales team for one. <https://help.traveltime.com/en/articles/8523972-attribution-guidelines>
3. **The paid plan is sales-only and annual.** Production is a fixed annual subscription sized by provisioned throughput in hits per minute, with a minimum 12-month term and no published price — the page says "Contact us for a quote". There is no pay-as-you-go tier to fall back on, so the realistic cost of a public site on TravelTime is a yearly contract negotiated by email. <https://traveltime.com/pricing>
4. **Attribution, if you do license it.** A table of journey times counts as indirect use, so the required text is "Location data analysis provided by TravelTime" linked to <https://docs.traveltime.com/api/overview/introduction>. Direct visuals such as an isochrone on a map need only "TravelTime" with the same link. The Terms also require the TravelTime logo or name on the page where the data appears. The current credit in `index.html` ("Travel times by TravelTime", unlinked) does not meet either wording. <https://docs.traveltime.com/api/overview/attribution>
5. **Caching and redistribution are restricted.** Caching is permitted only where the Order expressly allows it, refreshed at least every 60 days and deleted on termination. The CSV download hands raw travel times to visitors, which sits close to the clause forbidding you to "publish, distribute... any part of the... Service"; worth raising explicitly in any sales conversation.

## 2. Get Information About Schools

6. GIAS establishment data is Crown copyright released under the **Open Government Licence v3.0**, which permits commercial and non-commercial reuse with attribution. Use the default OGL statement, since DfE publishes no dataset-specific one: **"Contains public sector information licensed under the Open Government Licence v3.0."** <https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/>
7. The GIAS Acceptable Use Policy adds a condition that matters for a public site: you must not combine GIAS data with other sources to create or infer personal data, or attempt to re-identify individuals. Your pipeline keeps only institutional fields (URN, name, type, postcode, website, coordinates), so it complies — but do not add the head teacher name and contact columns that the full extract carries. <https://get-information-schools.service.gov.uk/AcceptableUsePolicy>

## 3. Explore Education Statistics, 16 to 18 results

8. The publication "A level and other 16 to 18 results" is accredited official statistics from DfE, released under the **Open Government Licence v3.0**. The same OGL attribution line covers it; add a source credit naming the publication and academic year, for example "Source: Department for Education, A level and other 16 to 18 results, 2024/25". <https://explore-education-statistics.service.gov.uk/find-statistics/a-level-and-other-16-to-18-results/2024-25>
9. Publishing school-level performance figures carries a presentational obligation rather than a legal one: the data guidance explains the suppression codes and the exclusions (special schools, pupil referral units, alternative provision), and a public site should say that a blank means "not published", not "no results". Your research note already documents this. <https://explore-education-statistics.service.gov.uk/find-statistics/a-level-and-other-16-to-18-results/2024-25/data-guidance>

## 4. postcodes.io

10. **No published terms, no published rate limit, no SLA.** The docs state only that no authentication is required. There is no terms-of-service page, no documented fair-use policy, and no availability guarantee. Calling it from browser code is normal practice and the service sends permissive CORS headers — your page already does it — but you would be depending on a free service with no commitment behind it. <https://postcodes.io/docs/overview/>
11. **Self-hosting is the answer to volume.** The project ships Docker images for the API and a pre-seeded PostGIS database. If the site gets real traffic, run your own copy rather than leaning on the public endpoint. <https://postcodes.io/docs/self-host/>
12. **Attribution is required and currently missing.** The licences page lists: "Contains OS data © Crown copyright and database right 2025", "Contains Royal Mail data © Royal Mail copyright and database right 2025", "Contains National Statistics data © Crown copyright and database right 2025", and for Scotland "Contains NRS data © Crown copyright and database right 2025". Source code is MIT. <https://postcodes.io/docs/licences/>
13. **Northern Ireland postcodes are the one commercial trap.** BT postcode data comes under the ONSPD licence and commercial use needs a separate licence from NI Land and Property Services; non-commercial use is unrestricted. Your app is England-only, so restrict lookups to GB or accept this limit knowingly.

## 5. Privacy and UK GDPR

14. A postcode on its own is generally not personal data, but the ICO's test is contextual: it becomes personal data when combined with other information reasonably likely to identify someone. A visitor's own home postcode arriving alongside their IP address, on a request you could log, is realistically personal data. Assume UK GDPR applies. <https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/personal-information-what-is-it/what-is-personal-information-a-guide/>
15. The cheapest compliance posture is to make the claim true rather than argue it: do not log request bodies or IP addresses, keep Cloudflare Workers logging off or scrubbed, set no cookies, add no analytics. With no cookies and no non-essential storage, PECR imposes no consent banner.
16. A minimal privacy notice (UK GDPR Article 13) needs: who you are and how to contact you; that the postcode you enter is sent to postcodes.io to find coordinates and to the travel-time provider to calculate journey times; the lawful basis (legitimate interests, namely answering the search you asked for); that nothing is stored or logged; who the recipients are, with a note if any sits outside the UK; that you have rights of access, erasure and objection, though there is nothing held to act on; and the right to complain to the ICO.
17. One sentence in the page footer linking to a short notice is enough. Non-commercial personal or household processing can be exempt from the ICO data protection fee, but a public site is arguably beyond "personal or household", so check the ICO self-assessment before deciding not to register.

## 6. Alternatives for public-transport travel-time matrices

18. **Self-hosted OpenTripPlanner 2** is the only option that is free, legal for public use, genuinely one-to-many, and UK-complete. Feed it Bus Open Data Service timetables (OGL, statutory since 2020) plus OpenStreetMap; its Travel Time sandbox API produces one-to-many times directly. The cost is a virtual machine with a few GB of RAM — OTP is a JVM application and cannot run on Cloudflare Workers, so Workers would front it rather than host it. Rail timetables need a separate feed via the Rail Data Marketplace. <https://docs.opentripplanner.org/en/v2.2.0/sandbox/TravelTime/>
19. **Google Routes API** supports transit in `computeRouteMatrix` but caps a transit request at 100 elements, against your 2,000 destinations — 20-plus billed requests per search, and the legacy Distance Matrix API is closed to new projects. Practical only if you cut the candidate list first. <https://developers.google.com/maps/documentation/routes/transit-rm>
20. **Geoapify** has a free tier of 3,000 daily credits and a Route Matrix API taking up to 1,000 sources and targets, but the matrix supports driving, truck and walking only — no transit. Fine as a fallback for the driving, cycling and walking modes, useless for the main one. <https://apidocs.geoapify.com/docs/route-matrix/>
21. **HERE** splits the capability the wrong way: Matrix Routing covers car, truck, bicycle and pedestrian, while public transit lives in a separate point-to-point Transit API with no matrix endpoint. <https://docs.here.com/routing/docs/matrix-v8-transport-modes>
22. **Navitia** (hove-io) offers a hosted API with a free developer tier and an open-source self-hosted engine, but UK coverage on the hosted service depends on which GTFS regions are loaded and is not guaranteed; verify coverage for your target area before relying on it. Self-hosting Navitia with BODS data is the same shape of work as OTP. <https://doc.navitia.io/>

**Recommendation:** publish on the two OGL datasets with the attribution lines in points 6, 8 and 12, drop TravelTime from the public deployment, and either self-host OpenTripPlanner behind the Worker or email TravelTime sales for a non-commercial Order before going live.
